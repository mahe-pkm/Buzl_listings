# Skill — UI Implementation

## Design source

Use the approved Buzl design system from:

- `docs/design/DESIGN_SYSTEM.md`
- `docs/design/DESIGN_TOKENS.md`

## Rules

- use semantic tokens
- maintain consistent spacing/type/radius
- preserve visible focus states
- use accessible labels
- support keyboard interaction
- build mobile-first responsive behavior
- avoid unnecessary client-side JavaScript on SEO pages

If a required token/component pattern is not documented, stop and record the gap rather than inventing a new visual system.

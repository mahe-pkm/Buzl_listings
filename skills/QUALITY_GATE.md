# Skill — Quality Gate

Before marking an implementation task complete, run the checks relevant to that task.

Typical checks after application scaffolding exists:

- formatting
- lint
- typecheck
- unit/integration tests
- build
- migration validation
- RLS/security review for data changes
- responsive UI check
- accessibility check
- SEO metadata/schema check for public pages

Document unavailable or failing checks in `docs/CURRENT_STATE.md`.

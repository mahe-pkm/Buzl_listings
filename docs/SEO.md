# SEO & Citation Requirements

SEO is part of the platform architecture.

## Public pages

Each public listing should have:

- canonical URL
- unique title
- unique meta description where data allows
- semantic headings
- business NAP
- category
- address
- map/directions link
- business hours
- services
- breadcrumbs
- Open Graph metadata
- structured data

## Structured data

Primary candidate:

- `LocalBusiness` or a more specific subtype

Additional schemas where valid:

- `Organization`
- `WebSite`
- `BreadcrumbList`

Generate schema only from actual stored business data.

## Citation integrity

The business name, address, and phone number must remain consistent wherever rendered.

## Technical SEO

- XML sitemap
- robots.txt
- clean URLs
- crawlable pagination
- internal linking
- mobile-first output
- good Core Web Vitals
- accessible HTML

# Feature — Authentication

## MVP

- register
- login
- logout
- password recovery if password auth is enabled
- protected owner dashboard
- profile record
- role-aware navigation

## Preferred backend

Supabase Auth.

## Initial roles

- `admin`
- `business_owner`
- `user`

Roles must come from trusted database/server state.

## Later

- magic link
- OTP
- Google login
- team/business staff access
